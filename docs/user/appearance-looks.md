# Interface looks

A look changes more than colors. Themes pick a palette for the standard interface; a look
restyles the interface itself: type, shapes, surfaces, and spacing. T3 Neo ships two looks on web
and desktop.

- **Neo** is the T3 Neo interface and the default: a warm canvas with cream text and a single
  amber accent, flat bordered panels instead of glass, pill-shaped buttons and controls, lighter
  display headings with tight letter spacing, small uppercase labels, and an amber starfield: a
  denser patch behind the sidebar brand and a fine scatter of tiny glints over the sidebar and the
  top bar, some of which twinkle or briefly flash now and then. The chat itself stays clear. In light appearance the canvas turns warm sand and the accent deepens for
  contrast.
- **Default (Themes)** is the standard T3 Code interface, where themes pick the palette. Under Neo the theme library is hidden: Neo owns its light and dark palette, and only the appearance mode (system, light, dark) stays selectable.

To switch:

1. Open **Settings**.
2. Select **Appearance**.
3. Choose a look under **Look**.

The look is a per-client choice stored on the device, like the theme. It applies before the first
paint, so a reload never flashes the other look. While Neo is active, the selected theme's palette
is replaced by Neo's own colors; switch to **Default (Themes)** to use themes again. Contrast, glass
opacity, and font settings keep working under both looks.

**Agent controls** in Settings → Appearance decides how the model picker, the context and speed
options, and the Build/Plan and access controls in the message box look. **Top bar style**, the
default, gives them the same bordered pills as **Open** and **Commit** in the header. **Default
style** keeps the plain buttons of T3 Code. The choice is stored on the device and works under both
looks.

Neo brings its own interface font, Schibsted Grotesk, which ships with the app. The **Interface
font** picker in Settings → Appearance pins it at the top with a **Neo Default** badge, right above
your platform's own face (SF Pro on macOS, Segoe UI on Windows) marked **Default**. Under Neo an
unset preference means Schibsted Grotesk; under Default (Themes) it means the platform face. Either
one, or any installed font, can be chosen explicitly regardless of the look.
